## About The Project

CyberPass Gen is a password generator that creates strong, memorable passwords by combining dictionary words with random symbols and numbers. It's built with a focus on security, user experience, and a unique "cyberpunk" design.

This project was built to explore modern web development techniques and to create a password generator that is both highly secure and easy to use.

### Key Features

*   **Memorable Passwords:** Generates passwords using a combination of words, making them easier to remember than random strings of characters.
*   **High Entropy:** Appends random symbols and numbers to the word-based password to increase its entropy and resistance to brute-force attacks.
*   **Instant Generation:** Passwords are generated instantly on the client-side, with no data ever leaving your browser.
*   **Password Strength Indicator:** Provides immediate feedback on the strength of the generated password.
*   **Copy to Clipboard:** Easily copy the generated password to your clipboard with a single click.
*   **Responsive Design:** A sleek, modern design that works on all devices.
*   **Cool Animations:** Engaging animations and a retro-futuristic aesthetic.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

*   Node.js (v18.x or later)
*   npm

### Installation

1.  Clone the repo
    ```sh
    git clone https://github.com/your_username_/cyber-pass-gen.git
    ```
2.  Install NPM packages
    ```sh
    npm install
    ```
3.  Run the development server
    ```sh
    npm run dev
    ```

The application will be available at `http://localhost:9002`.
